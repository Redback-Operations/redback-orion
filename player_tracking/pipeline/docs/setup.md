## Conventions

- `data/raw/` = training data only (image/label pairs). No videos, no outputs.
- `data/videos/` = raw match footage, named to match its dataset folder
  (`gcs_vs_car.mp4` → `data/raw/gcs_vs_car/`).
- `outputs/` = anything generated by inference. Never mix back into `data/`.

re-download from Drive if lost. After generating a new derived dataset or
trained model locally, upload it to the matching Drive folder.

### Restoring from Drive

```bash
pip install gdown
python scripts/download_data.py              # everything (data, datasets, models)
python scripts/download_data.py data models  # or pick specific folders
```

`scripts/download_data.py` downloads the Drive subfolders into the matching
local folders. Requires the Drive folder to stay shared as "anyone with the
link can view".
