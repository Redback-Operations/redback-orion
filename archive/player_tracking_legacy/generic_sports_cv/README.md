# Generic sports computer vision

Computer vision experiments on sports other than AFL, mostly from 2024 and 2025. None of it is part of the Orion pipeline. Some ideas carry over, such as small object detection for the ball, pose estimation and depth estimation.

| Folder | What it is |
|---|---|
| `Player_Tracking_And_Ball_Speed_Estimation/` | YOLOv8 player and ball tracking with ball speed estimates (soccer) |
| `Player_Tracking_Data_science/` | Player, ball, goalkeeper and referee detection plus pitch keypoints (soccer) |
| `Small_Object_Detection/` | Fine-tuning experiments for detecting small objects |
| `YOLOV3_Model/` | YOLOv3 training setup and configs |
| `Object_Depth_Estimation/` | Distance estimates from a single image |
| `Pose_Matching_project/` | Pose estimation and matching |
| `Movenet_pose_tracking/` | MoveNet body keypoint notebooks |
| `MMA_tracking/` | OpenPose pose estimation on MMA footage |
| `tennis_tracking/` | Tennis player pose and movement analysis |
| `Fencing/` | Pose and weapon detection in fencing |
| `boxing_action_detection/`, `boxing_detection/` | Punch, kick and boxing bag detection |
| `Olympic_racing/` | YOLOv11-Pose and SAM2 on Olympic racing footage |
| `greyhound_tracking/` | Greyhound detection and tracking |
| `Prac.ipynb`, `Prac_2.ipynb`, `player*.jpeg` | MediaPipe pose practice notebooks and test images |
